Braids method

Creating the Braid Infographics in Illustrator

Level 1 Containers

Use https://hcmc.uvic.ca/project/braidednarratives/svg-machine/ to create a rectangle for each Level 1 Container. For our visualizations, width = 450 pixels and height = # of pages x 10 pixels. We used the following colour scheme:

colour Scheme
Red db4105
Blue 3e8cc6
Yellow ffe666
Purple 8762a6
Green a9d164
  1. Use the alignment tool to center each title in each rectangle and group each pair together.
  2. Place the last rectangle on the bottom of your workspace
  3. Rotate the second to last rectangle so it sits on top of it. (To help snap to object, go to view menu and make sure only “snap to point” is selected.)
  4. Alternate for all the rectangles.
  5. Select all and drag the image, so the bottom left corner is on one of the grid boxes one up from the bottom.
  6. Draw a line from the bottom to the top at a 45% diagonal through the image to create a center. Move the image to center it.
  7. Draw two parallel lines on either side. One should start five boxes up. The other should start five boxes across.
  8. Shrink the width of the rectangles (the 450 dimension) to make a triangle with the diagonal line.
  9. Use the selection clicker to curve the top corner of the triangle you just created. If you pull it down far enough, it should turn into a red semi-circle indicating that you have reached the other edges of the shape. Do this for all the triangles.

Level 2 Containers (for containers that fill up the entire Level 1 Container)

  1. Use https://hcmc.uvic.ca/project/braidednarratives/svg-machine/ to create a rectangle for each Level 2 Container. Use colours and dimensions that agree with what you did for the Level 1 Containers.
  2. Use the alignment tool to center each title in each rectangle and group each pair together.
  3. Select all the Level 2 Containers that belong in a Level 1 Container.
  4. Use the Alignment tool to distribute those rectangles on top of each other. Group everything together.
  5. Copy and Paste the Level 1 Container from your braid.
  6. Re-size the Level 2 block so it is the same height as the Level 1 Container. Press shift to ensure the text does not get distorted, this will mean the resulting image is the same height as the Level 1 Container, but not the same width.
  7. Now, ungroup the Level 2 block and ungroup each text from its rectangle. Then group the rectangles together and move them away so you can group the text together.
  8. Select the group of Level 2 Rectangles and click expand appearance.
  9. Drag the group of Level 2 Rectangles on top of the Level 1 container. Make it wider than the Level 1 Container and send it to back.
  10. Select both the Level 1 Container and Level 2 Rectangles and click Clipping Mask Make. This will cut the Level 2 Rectangles to the same size and shape as the Level 1 Container. Paste the Level 1 Container again and put it behind the Level 2 Shape. This will allow the edges of the Level 1 Container to define the Level 2 Shape.
  11. Reduce the width of the Level 2 Shape, so it is about half the size of the Level 1 Container.
  12. Drag the text back onto the Shape, so each title is centered in its appropriate container.
  13. Group everything together and place it in the larger braid.

Level 2 Containers (For Containers that don’t fill up the entire Level 1 Container)

  1. Create a rectangle where the width is 225 and the height= #of pages x 5 pixels. colour the rectangle according to its narrator or status.
  2. Create a box to help you locate the container in the Level 1 Container. The height of the box should equal # of pages into the Level 1 Container that the level 2 container appears x 10 pixels.
  3. Align that box with the top of the Level 1 Container. Distribute the Level 2 Container Rectangle under the box. Delete the box.
  4. Add text to the Level 2 Container.
  5. Change the outer corners of the Level 2 so they are both curved.
