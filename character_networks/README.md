## Character Networks

This folder contains the scripts necessary to build social networks using Gephi.

## UVic_database

This folder contains a script that backs up the databases. It also includes a script that will export the necessary .csv files from those databases. 

## gephi_toolkit

This folder contains a script that will run gephi heedlessly. To run that script, you must navigate to gephi-toolkit (folder inside gephi_toolkit) in terminal. Then run mvn clean compile
mvn exec:java -Dexec.mainClass=edu.youruniversity.vbn.App
